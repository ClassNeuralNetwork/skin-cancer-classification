# Imagens sintéticas DeepSMOTE

Esta pasta recebe automaticamente as imagens sintéticas produzidas por `03_transfer_learning/deep_smote/01_generate_deepsmote_dataset.ipynb` ou `deepsmote_images.py`.

As imagens são geradas em PNG, separadas em subpastas por classe. Elas não são versionadas porque podem ser regeneradas; os metadados e vetores correspondentes ficam no diretório pai `data/deepsmote/`.
