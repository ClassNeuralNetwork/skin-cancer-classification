# Resultados

Os resultados são separados por tipo de artefato:

```text
results/
├── figures/           # curvas, matrizes de confusão e exemplos visuais
├── metrics/           # métricas tabulares dos modelos individuais
├── ensembles/         # predições, métricas e exemplos dos ensembles
└── training_history/  # histórico de treinamento
```

O nome de cada resultado deve permitir identificar o experimento que o gerou. Figuras com endereços de memória ou nomes automáticos devem ser tratadas como resultados legados e não usadas como referência no texto do TCC.
